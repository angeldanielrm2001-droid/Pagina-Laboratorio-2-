Este es un trabajo estudiantil con una empresa ficticia (Modulo 1.8 de primer año de bachillerato en Desarrollo de Software).
El inicio de sesión funciona sin comparar nada con la base de datos ni en ningún lugar.
De manera que cualquier correo y contraseña permite iniciar sesión. Si el correo contiene la palabra "admin" la sesión se inicia
como administrador. Esto, si fuera una pagina de un negocio real, no es para nada seguro; se realizo así para facilitar las pruebas.
Ambas sesiones (usuario y administrador) contienen su respectivo panel con acciones especiales.

Todos los formularios que contiene la pagina envían su información a una base de datos simple en Hojas de Calculo de Google.
Esto se logra mediante JS, HTML y la extensión Apps Script.

Aun se pueden añadir muchas mejoras a la pagina, como añadir las imágenes del producto en lugar de las figuras actuales, añadir y mejorar
las funciones del panel de administrador y usuario. Y como se menciona en el inicio, hacer un verdadero inicio de sesion seguro.
Considérese que el trabajo fue hecho en un par de horas.
